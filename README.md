# AI Banking Assistant

## Project Overview
The AI Banking Assistant is a Python application that uses specialized agents to answer banking-related questions through a Streamlit dashboard.

## Features
- Account balance inquiry
- Transaction history
- Suspicious transaction screening
- Loan eligibility demonstration
- AI banking chat

## AI Agents
1. Banking Agent – Handles account and transaction queries.
2. Fraud Agent – Flags potentially suspicious transactions.
3. Credit Agent – Calculates a demonstration debt-to-income ratio.

## Technologies Used
- Python
- Streamlit
- Ollama
- Llama 3.2 (1B)
- Visual Studio Code

## How to Run
1. Open the project folder in VS Code.
2. Activate the project's virtual environment.
3. Run this command in the terminal:

   `streamlit run dashbord.py`

4. Open `http://localhost:8501` in your browser.

## Disclaimer
This project uses sample banking data for demonstration purposes. It is not connected to a real bank and does not provide official fraud or loan decisions.
